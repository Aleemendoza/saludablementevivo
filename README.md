# Saludablemente Vivo

Storefront premium para alimentos saludables, construido con Next.js 15 y TypeScript.

## Inicio

```powershell
npm install
npm run dev
```

Abrí `http://localhost:3000`.

Para comprobar la compilación de producción:

```powershell
npm run build
```

Requiere Node.js 20.9 o superior (incluye npm). No usa pnpm.
